# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, pull requests, or discussions.

Report them privately instead, using either:

- GitHub Security Advisories: open the repository's **Security** tab and click **Report a vulnerability**.
- Email: security@tsuga.com

Include a description of the issue, the affected version or commit, and steps to reproduce if you have them. We will acknowledge your report and keep you informed as we investigate.
